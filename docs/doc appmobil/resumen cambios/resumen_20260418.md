## Fix de compilacion Android — Kotlin incremental cache

### Error observado
`Daemon compilation failed` de Kotlin con cierre fallido de caches incrementales en `build/workmanager_android/kotlin/`.
Causa: rutas en discos distintos (D: cache Flutter, E: proyecto) en Windows genera conflicto en el cache incremental del plugin `workmanager_android`.

### Solucion aplicada
`android/gradle.properties`:
```properties
kotlin.incremental=false
kotlin.incremental.useClasspathSnapshot=false
kotlin.caching.enabled=false
```

Limpieza tecnica ejecutada:
- `./gradlew --stop`
- `flutter clean`
- limpieza de carpetas `build/` y `.gradle/`
- `flutter pub get`

### Verificacion
`flutter build apk --debug` — compilacion exitosa.
APK generado en `build/app/outputs/flutter-apk/app-debug.apk`.

### Nota
Tradeoff: builds mas lentos al desactivar incremental Kotlin.
Recomendacion futura: unificar `PUB_CACHE` en el mismo disco que el proyecto (E:) y reactivar incremental de forma controlada.
