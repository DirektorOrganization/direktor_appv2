## 6. Renderizado de indicadores en el Hub (`_IndicatorSection`)

### 6.1 Layout de dos columnas para tarjetas

Los indicadores habilitados se clasifican en:
- **`card`** → se emparejan de 2 en 2 en una fila usando `IntrinsicHeight` + `Row(Expanded, Expanded)`. Si queda uno solo al final, va a ancho completo.
- **`chart_donut`** / **`chart_bar`** → siempre ancho completo, rompen cualquier par de tarjetas pendiente.

### 6.2 Widget de tarjeta (`_buildCardWidget`)
Diseno vertical compacto: icono circular → valor grande → label → sublabel. Optimizado para media anchura de pantalla.

### 6.3 Widget donut (`_buildDonutWidget`)
- `CustomPainter` (`_DonutPainter`) que dibuja:
  - Arco de fondo gris (`Color(0xFFE0EAF6)`)
  - Arco de progreso con color del indicador, trazo de 12px, `strokeCap: StrokeCap.round`
  - Inicio desde `-pi/2` (tope)
  - Porcentaje en el centro del circulo
- Panel derecho: label, sublabel, `LinearProgressIndicator`, texto "X% completado".
- Usa `dart:math` para calculos trigonometricos.

### 6.4 Widget bar chart (`_buildBarWidget`)
- Cabecera con icono + label.
- Una fila por cada `_BarItem`: label fijo 82px + `LinearProgressIndicator` proporcional al maximo + valor numerico.
- Colores individuales por barra.

### 6.5 Datos por indicador (`_resolveData`)
Funcion privada que resuelve label, value, color, icon, sublabel, `donutPercent` y `barItems` segun el `pref.key`. Colores de cumplimiento graduados: verde ≥80%, amarillo ≥50%, rojo <50%.

## 7. Seed defaults y merge con DB

### Bug corregido: indicadores desaparecian al deshabilitar uno

**Causa:** Al deshabilitar un indicador, se guardaba ese pref en DB. Como `raw` ya no estaba vacio, se descartaba el fallback a `_seedPrefs`, perdiendo los demas 3 que nunca fueron guardados.

**Solucion — merge por clave:**
```dart
final seedMap = {for (final p in _seedPrefs) p.key: p};
final rawMap  = {for (final p in raw) p.key: p};
final prefs   = {...seedMap, ...rawMap}.values.toList();
```

Los seeds son la base; los valores de DB ganan por clave. Garantiza que indicadores nunca tocados por el usuario sigan mostrando su estado por defecto.

`_seedPrefs` definido como `static final` dentro de `_IndicatorSection`:
```dart
static final _seedPrefs = [
  HubIndicatorPref(key: 'res_cumplimiento', userId: 0, isEnabled: true,
      displayType: 'chart_donut', sortOrder: 0),
  HubIndicatorPref(key: 'res_vencidas',     userId: 0, isEnabled: true,
      displayType: 'card', sortOrder: 1),
  HubIndicatorPref(key: 'res_en_proceso',   userId: 0, isEnabled: true,
      displayType: 'card', sortOrder: 2),
  HubIndicatorPref(key: 'hit_activos',      userId: 0, isEnabled: true,
      displayType: 'card', sortOrder: 6),
];
```
